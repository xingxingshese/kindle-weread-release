# Kindle 微信读书

这里发布 Kindle 微信读书的安装包，适用于已越狱、能运行自定义应用的 Kindle Paperwhite 第七代（PW3）。目标固件为 5.16.2.1.1。

## 安装 v0.01

1. 下载 [kindle-weread.zip](https://github.com/xingxingshese/kindle-weread-release/releases/download/v0.01/kindle-weread.zip)，在电脑上解压。
2. 将 `documents`、`extensions`、`fonts`、`weread` 合并复制到 Kindle 根目录，覆盖同名文件。
3. 安全弹出后，在文档列表或 KUAL 菜单打开微信读书，用手机微信扫码登录。

书架支持搜书和分组。读书时点两侧翻页，点中间打开目录、字号和排版设置。「我的 → 设置」可选择日历或图片屏保。「我的 → 版本信息」可检查后续更新。

v0.01 支持普通 EPUB、TXT 和公众号图文。会员专享章节的完整阅读仍待完成。公众号目录遇到 `-2041` 时可先读本机缓存。 [发行记录](https://github.com/xingxingshese/kindle-weread-release/releases)
