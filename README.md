# Kindle 微信读书

这里发布 Kindle 微信读书的安装包，适用于已越狱、能运行自定义应用的 Kindle Paperwhite 第七代（PW3）。目标固件为 5.16.2.1.1。

## 安装 v0.04

从 v0.02 升级，请打开「我的 → 版本信息 → 检查更新」，下载增量包，退出后重新打开应用。首次安装请使用完整包。

1. 下载 [kindle-weread.zip](https://github.com/xingxingshese/kindle-weread-release/releases/download/v0.04/kindle-weread.zip)，在电脑上解压。
2. 将 `documents`、`extensions`、`fonts`、`weread` 合并复制到 Kindle 根目录，覆盖同名文件。
3. 安全弹出后，在文档列表或 KUAL 菜单打开微信读书，用手机微信扫码登录。

书架支持搜书和分组。读书时点两侧翻页，点中间打开目录、字号和排版设置。「我的 → 设置」可选择日历或图片屏保。「我的 → 版本信息」可检查后续更新。

v0.02 支持在书籍正文中划线、查看段落想法、写想法和回复书评。公众号目录暂时不可用时，可读已缓存的目录或封面文章。会员章节未返回正文时，可从官方阅读页继续。 [发行记录](https://github.com/xingxingshese/kindle-weread-release/releases)

## 接收 Beta 版本

安装 v0.04 后，在「我的 → 版本信息」打开「接收 Beta 版本」。开关默认关闭，打开时自动检查预发布版，确认下载安装后退出并重新打开应用。关闭开关后，后续只检查更高版本的正式版。

[v0.10-beta.1](https://github.com/xingxingshese/kindle-weread-release/releases/tag/v0.10-beta.1) 更新「我的」页面、日历锁屏、书籍划线与公众号文章分页。版本信息移到「我的 → 设置」。v0.09 可使用 [9→10 增量包](https://github.com/xingxingshese/kindle-weread-release/releases/download/v0.10-beta.1/kindle-weread.9-to-10.zip)，首次安装以及 v0.08 或更早版本使用[完整安装包](https://github.com/xingxingshese/kindle-weread-release/releases/download/v0.10-beta.1/kindle-weread.zip)。

[v0.09-beta.1](https://github.com/xingxingshese/kindle-weread-release/releases/tag/v0.09-beta.1) 修正书页末行和阅读工具栏，恢复锁屏设置。v0.08 可使用相邻版本增量包，更早版本和首次安装使用[完整安装包](https://github.com/xingxingshese/kindle-weread-release/releases/download/v0.09-beta.1/kindle-weread.zip)。

[v0.08-beta.1](https://github.com/xingxingshese/kindle-weread-release/releases/tag/v0.08-beta.1) 修正休眠唤醒：阅读正文、已展开的排版面板或确认框会恢复到休眠前的状态。v0.04 至 v0.07 提供增量包。[下载 v0.08 Beta 完整包](https://github.com/xingxingshese/kindle-weread-release/releases/download/v0.08-beta.1/kindle-weread.zip)

[v0.07-beta.1](https://github.com/xingxingshese/kindle-weread-release/releases/tag/v0.07-beta.1) 更新了 PW3 书籍选词、词典、划线评论、笔记草稿、账号和本机阅读时长界面。已安装 v0.04、v0.05 或 v0.06 的用户可以增量升级。[下载 Beta 完整包](https://github.com/xingxingshese/kindle-weread-release/releases/download/v0.07-beta.1/kindle-weread.zip)

[v0.06-beta.1](https://github.com/xingxingshese/kindle-weread-release/releases/tag/v0.06-beta.1) 支持原生微信扫码、账号阅读时长、整页翻阅及长按选词。v0.04 和 v0.05-beta.1 可在应用内增量更新。较早版本可通过 USB 安装本页的 Beta 完整包。
